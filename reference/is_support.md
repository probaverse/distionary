# Test for a Support Object

`is_empty_support()` tests whether a support is the empty one: no atoms
and no continuous part. It is `FALSE` for anything that is not a
support.

## Usage

``` r
is_support(x)

is_empty_support(x)
```

## Arguments

- x:

  Object to test.

## Value

`TRUE` if `x` is a support object, otherwise `FALSE`.
